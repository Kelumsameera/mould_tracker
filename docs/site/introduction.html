#About Mould Tracker

Mould Tracker shows where every injection mould and extrusion die tool is, what condition it is in, and what work was done on it. Production, the Mould Room and the workshop all see the same live information.

#What you can do

Task Where
See where a mould is now: on a machine, on the production floor, in the Isolation Area, in the Mould Room or in the workshop Find a mould
See the storage position of a mould on the rack layout Find a storage position
Move a mould and record where it went Move a mould
Record service and repair work, problems and production shots Record work
Look up moulds without signing in View moulds without signing in

Every move follows the rules set by your administrator. Moves away from a machine go through the Isolation Area first. Mounting a mould on a machine is direct.

#Two ways to use it

  • Without signing in. Anyone on the factory network can open the app and see mould locations, details, pictures and the rack view. Nothing can be changed.
  • Signed in. You see the actions your role allows, such as moving moulds, recording work or managing racks.

#What is new

November 2026

  • View without signing in. The opening page now uses the same layout as the app: sidebar, search, language and theme controls, and mould cards.
  • Injection Moulds and Extrusion Die Tools tabs. Switch between the two tool types on the same page.
  • Location filters. Tap a location count, such as Machine or Mould Room, to show only the moulds there.
  • Live updates. The list refreshes on its own every few seconds, so a moved mould shows its new place without reloading.
  • Continuous scrolling. More moulds load as you scroll. There are no Next and Previous buttons.
  • Pictures. Mould cards show the product picture. Tap a mould, then tap the picture to enlarge it.
  • Mould and machine details. The mould sheet shows size, cavities, items, materials, the machine the mould is running on and the machines it can run on.
  • Rack view without signing in. Open the Rack view tab to see zones, racks and the moulds stored on them.

#Mould Tracker ගැන

Mould Tracker මගින් හැම injection mould එකක්ම සහ extrusion die tool එකක්ම දැන් තියෙන්නේ කොහෙද, එහි තත්ත්වය මොකක්ද, ඒකට කරපු වැඩ මොනවද කියලා පෙන්වනවා. Production, Mould කාමරය සහ workshop එක හැමෝටම එකම live තොරතුරු පේනවා.

#භාවිත කරන ක්‍රම දෙක

  • Login නොවී. Factory network එකේ ඕනම කෙනෙක්ට app එක open කරලා mould තිබෙන තැන්, විස්තර, පින්තූර සහ rack view එක බලන්න පුළුවන්. කිසිම දෙයක් වෙනස් කරන්න බැහැ.
  • Login වෙලා. ඔබේ role එකට අවසර තියෙන කාර්යයන් පේනවා: moulds මාරු කිරීම, වැඩ සටහන් කිරීම, racks කළමනාකරණය වගේ.

#අලුතින් එකතු වූ දේ

2026 නොවැම්බර්

  • Login නොවී බැලීම. මුල් පිටුව දැන් app එකේම layout එක භාවිත කරනවා: sidebar, search, භාෂා සහ theme controls, mould cards.
  • Injection Moulds සහ Extrusion Die Tools tabs. එකම පිටුවේ tool වර්ග දෙක අතර මාරු වෙන්න.
  • Location filters. Machine හෝ Mould කාමරය වගේ location count එකක් තට්ටු කරලා එතන තියෙන moulds විතරක් බලන්න.
  • Live updates. List එක තත්පර කිහිපයකට වරක් ඉබේම refresh වෙනවා. ඒ නිසා mould එකක් move කළාම reload නොකර අලුත් තැන පේනවා.
  • නොනවත්වා scroll කිරීම. පහළට scroll කරද්දී තවත් moulds load වෙනවා. Next / Previous බොත්තම් නැහැ.
  • පින්තූර. Mould cards වල product පින්තූරය පේනවා. Mould එකක් තට්ටු කරලා, පින්තූරය තට්ටු කළාම විශාල වෙනවා.
  • Mould සහ මැෂින් විස්තර. Mould sheet එකේ ප්‍රමාණය, cavities, items, materials, දැනට දාලා තියෙන මැෂිම සහ යොදන්න පුළුවන් මැෂින් පේනවා.
