#Quick start

#Find a mould

Open Find a mould, then search for a mould ID, product ID or description. Select the matching mould to see its current location and condition.

#Read the location

A storage label such as FLK-A-P1-1 means zone FLK, rack A, pallet/level P1, position 1. Use Rack view to see the physical layout.

#Record a movement

If you have movement access, open the mould and choose its destination. Check that the selected machine or storage position matches the physical destination before saving.

#Record a problem or completed work

Use Report a problem to describe an issue. Use the work log to record completed work when that action is available to you.

See Using Mould Tracker for the full list of user guides.

#ඉක්මන් ආරම්භය

#Mould එකක් සොයාගන්න

Find a mould විවෘත කර mould ID, product ID හෝ විස්තරය ඇතුළත් කරන්න. ගැළපෙන mould එක තෝරා එහි වත්මන් පිහිටීම සහ තත්ත්වය බලන්න.

#ගබඩා ස්ථානය කියවන්න

FLK-A-P1-1 යනු FLK කලාපය, A rack එක, P1 pallet/තට්ටුව සහ 1 ස්ථානයයි. භෞතික සැලැස්ම බැලීමට Rack view භාවිත කරන්න.

#මාරු කිරීමක් සටහන් කරන්න

Mould මාරු කිරීමට අවසර තිබේ නම් mould එක විවෘත කර ගමනාන්තය තෝරන්න. Save කිරීමට පෙර තෝරාගත් machine එක හෝ ගබඩා ස්ථානය සැබෑ ගමනාන්තයට ගැළපෙන බව තහවුරු කරන්න.

#ගැටලුවක් හෝ කළ වැඩ සටහන් කරන්න

ගැටලුවක් විස්තර කිරීමට Report a problem භාවිත කරන්න. කළ වැඩ සටහන් කිරීමට අවසර තිබේ නම් work log එක භාවිත කරන්න.

සියලු උපදෙස් සඳහා Mould Tracker භාවිතය බලන්න.
