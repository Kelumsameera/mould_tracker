#Mould Tracker documentation

Entry point and reading paths for the Mould Tracker documentation suite

👥 EveryoneVerified (static code review + automated tests)Verified 2026-10-29web/API 2.0.0 (package.json); native shells 2.2.0

Mould Tracker is a web app (installable as a PWA, with Windows and Android shells) that records where every injection mould and extrusion die is, what condition it is in, and what work was done on it.

Start here: MOULD-TRACKER-COMPLETE-GUIDE.md — the standalone manual.

#Reading paths by role

You are… Read in this order
Production Supervisor First login → Quick start → Find a mould → Report a problem → Mount and unmount
Mould Technician Quick start → Move a mould → Work log → Shot count and service
Mould Maker Quick start → Workshop queue → Workshop repair cycle → Rack view
Admin Roles overview → Manage moulds → Machines → Users → Work log report
Super Admin Admin path + Rack management → Out of Service → Audit log
System Administrator / IT User access → Configuration → Security → Operations → Deployment
Developer Architecture → Repository → Local development → API → Database
