#Install and personalise the app

#Install

Connect to your workplace Wi-Fi or LAN, open the installation page, and select the download for your device. If the HTTPS setup link fails to open, use the HTTP installation link supplied by IT. The workplace server must be running whenever you use the app.

#Windows

  1. Download and open the Windows EXE installer. Windows 10/11, 64-bit is required.
  2. Follow the installer steps. From version 2.3.1, the installer includes factory certificate setup.
  3. Accept the Windows trust prompt for your workplace factory certificate. It is installed for the current Windows user. If setup fails or you decline the prompt, run the installer again to complete certificate setup.
  4. Open Mould Tracker from Start or the desktop and sign in with your assigned email and password.

The installer currently has no publisher code signature, so Windows may show an unknown-publisher warning. Confirm you downloaded it from your workplace installation page. The factory certificate stays trusted after uninstalling the app, allowing existing browser access to continue.

#Android

  1. Download and open the APK. Android 8 or later is required.
  2. When Android asks, allow your browser to install the app and tap Install.
  3. Open Mould Tracker and sign in with your assigned email and password.

The factory certificate is included in the APK. Separate certificate setup is unnecessary for the Android native app. Use email/password to sign in.

#Browser, iPhone/iPad and Mac

Follow the device certificate steps on the installation page before opening the HTTPS web app. In a supported browser, choose Install app. On iPhone/iPad, open the app in Safari and choose Share → Add to Home Screen. Apple native app downloads are currently unavailable.

Once setup is complete, open the app and sign in with your own account. Installation does not grant additional access.

#Language and appearance

Use EN / සිං to change the interface language. Use the sun or moon button to switch between light and dark themes.

#Connection

The app needs a working connection to load records and save changes. An offline screen does not mean that a movement or work entry has been saved. Reconnect and confirm the current record before repeating an action.

If a download fails, check the workplace connection and ask IT for the HTTP installation link. If Windows certificate setup fails, run the installer again. If the app reports a changed factory certificate, ask IT for an updated installer or APK.

For connection or sign-in problems, see Troubleshooting.

#Updates

The web interface receives updates from the workplace server. Windows and Android native apps from version 2.3.0 check for newer shell versions and offer an update. Earlier native versions need a manual update from the installation page. Android may ask you to allow Mould Tracker to install updates.

#App එක install කිරීම සහ සැකසීම

#Download කිරීම

Workplace Wi-Fi හෝ LAN එකට සම්බන්ධ වී installation පිටුව විවෘත කරන්න. ඔබගේ device එකට ගැළපෙන download එක තෝරන්න. HTTPS setup link එක විවෘත නොවේ නම් IT අංශයෙන් ලබාදුන් HTTP installation link එක භාවිත කරන්න. App එක භාවිත කරන විට workplace server එක ක්‍රියාත්මකව තිබිය යුතුයි.

#Windows install කිරීම

  1. Windows EXE installer එක download කර විවෘත කරන්න. Windows 10/11, 64-bit අවශ්‍යයි.
  2. Installer පියවර අනුගමනය කරන්න. Version 2.3.1 සිට factory certificate setup එක installer එකට ඇතුළත්.
  3. ඔබගේ ආයතනයේ factory certificate එක සඳහා Windows trust prompt එක accept කරන්න. Certificate එක දැනට භාවිත කරන Windows user account එකට install වේ. Setup එක අසාර්ථක වුවහොත් හෝ prompt එක ප්‍රතික්ෂේප කළහොත් certificate setup එක සම්පූර්ණ කිරීමට installer එක නැවත run කරන්න.
  4. Start menu හෝ desktop එකෙන් Mould Tracker විවෘත කර ඔබට ලබාදුන් email සහ password භාවිතයෙන් sign in වෙන්න.

Installer එකට දැනට publisher code signature එකක් නොමැති නිසා Windows unknown-publisher warning එකක් පෙන්විය හැකියි. File එක ආයතනයේ installation පිටුවෙන් ලබාගත් බව තහවුරු කරන්න. App එක uninstall කළ පසුවත් browser access සඳහා factory certificate එක trusted ලෙස පවතී.

#Android install කිරීම

  1. APK එක download කර විවෘත කරන්න. Android 8 හෝ ඊට අලුත් version එකක් අවශ්‍යයි.
  2. Android ඉල්ලන විට browser එකෙන් app එක install කිරීමට අවසර දී Install තෝරන්න.
  3. Mould Tracker විවෘත කර ඔබට ලබාදුන් email සහ password භාවිතයෙන් sign in වෙන්න.

Factory certificate එක APK එකට ඇතුළත්. Android native app එක සඳහා වෙනම certificate setup කිරීම අවශ්‍ය නැත. Sign in වීමට email/password භාවිත කරන්න.

#Browser, iPhone/iPad සහ Mac

HTTPS web app එක විවෘත කිරීමට පෙර installation පිටුවේ ඔබගේ device එකට අදාළ certificate පියවර අනුගමනය කරන්න. සහාය දක්වන browser එකක Install app තෝරන්න. iPhone/iPad එකක Safari තුළ app එක විවෘත කර Share → Add to Home Screen තෝරන්න. Apple native app downloads දැනට ලබාගත නොහැකියි.

Setup කිරීමෙන් පසු ඔබගේම account එකෙන් sign in වෙන්න. Install කිරීමෙන් ලැබෙන access එක වැඩි නොවේ.

#භාෂාව සහ පෙනුම

Interface භාෂාව වෙනස් කිරීමට EN / සිං භාවිත කරන්න. Light සහ dark themes අතර මාරු වීමට ඉර හෝ හඳ button එක භාවිත කරන්න.

#සම්බන්ධතාව සහ උදව්

Records ලබාගැනීමට සහ වෙනස්කම් save කිරීමට network connection එක අවශ්‍යයි. Offline screen එක පෙන්වන විට movement එකක් හෝ work entry එකක් save වී ඇති බව තහවුරු කළ නොහැකියි. නැවත සම්බන්ධ වී action එකක් නැවත කිරීමට පෙර record එකේ වත්මන් තත්ත්වය තහවුරු කරන්න.

Download link එක වැඩ නොකරන්නේ නම් workplace network එක පරීක්ෂා කර IT අංශයෙන් HTTP installation link එක ලබාගන්න. Windows certificate setup එක අසාර්ථක වුවහොත් installer එක නැවත run කරන්න. App එක certificate එක වෙනස් වී ඇති බව පෙන්වන්නේ නම් අලුත් installer එකක් හෝ APK එකක් සඳහා IT අංශය අමතන්න.

Connection හෝ sign-in ගැටලු සඳහා Troubleshooting බලන්න.

#Updates

Web interface එකට workplace server එකෙන් updates ලැබේ. Version 2.3.0 සිට Windows සහ Android native apps අලුත් shell version එකක් තිබේදැයි පරීක්ෂා කර update කිරීමට දැනුම් දෙයි. ඊට පෙර versions installation පිටුවෙන් අතින් update කළ යුතුයි. Updates install කිරීම සඳහා Mould Tracker වෙත අවසර දීමට Android ඉල්ලා සිටිය හැකියි.
