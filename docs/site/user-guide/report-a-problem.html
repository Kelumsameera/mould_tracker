#Report a problem

  1. Open the affected mould.
  2. Choose Report a problem.
  3. Describe the issue and when it was noticed.
  4. Add clear photos if they help explain it.
  5. Save the report and notify your supervisor when follow-up is urgent.

A problem report records the issue. It does not move the mould or automatically change its condition.

If the mould needs workshop attention, a person with the required access should record the appropriate movement and condition change.

#ගැටලුවක් වාර්තා කිරීම

  1. ගැටලුව ඇති mould එක විවෘත කරන්න.
  2. Report a problem තෝරන්න.
  3. ගැටලුව සහ එය දුටු වේලාව විස්තර කරන්න.
  4. ගැටලුව තේරුම් ගැනීමට උපකාරී නම් පැහැදිලි photos එකතු කරන්න.
  5. Report එක save කරන්න. ඉක්මන් පියවර අවශ්‍ය නම් supervisor දැනුවත් කරන්න.

Problem report එකෙන් ගැටලුව සටහන් වේ. එමගින් mould එක මාරු කිරීමක් හෝ එහි තත්ත්වය ස්වයංක්‍රීයව වෙනස් කිරීමක් සිදු නොවේ.

Mould එක workshop වෙත යැවිය යුතු නම් අවශ්‍ය අවසර ඇති පුද්ගලයෙකු අදාළ movement එක සහ තත්ත්ව වෙනස් කිරීම සටහන් කළ යුතුයි.
