#Find a mould

  1. Open Find a mould for injection moulds, or Extrusion Die Tools for extrusion dies.
  2. Enter a mould ID, product ID, description, machine or storage location.
  3. Use the available filters to narrow the results.
  4. Select a result to open its details.

#Check the details

Read the current location, condition, products and recent history before moving or using the mould. Product details can include descriptions, cavities and photos when these have been recorded.

If no result appears, check the spelling and clear the filters. Ask your supervisor if the mould has not yet been added.

For moulds in storage, see Find a storage position.
