# Find a mould

1. Open **Find a mould** for injection moulds, or **Extrusion Die Tools** for extrusion dies.
2. Enter a mould ID, product ID, description, machine or storage location.
3. Use the available filters to narrow the results.
4. Select a result to open its details.

## Check the details

Read the current location, condition, products and recent history before moving or using the mould. Product details can include descriptions, cavities and photos when these have been recorded.

If no result appears, check the spelling and clear the filters. Ask your supervisor if the mould has not yet been added.

For moulds in storage, see [Find a storage position](rack-view.md).

## සිංහල

1. Injection moulds සඳහා **Find a mould** හෝ extrusion dies සඳහා **Extrusion Die Tools** විවෘත කරන්න.
2. Mould ID, product ID, විස්තරය, machine එක හෝ ගබඩා ස්ථානය ඇතුළත් කරන්න.
3. ප්‍රතිඵල සීමා කිරීමට තිබෙන filters භාවිත කරන්න.
4. විස්තර බැලීමට ප්‍රතිඵලයක් තෝරන්න.

### විස්තර පරීක්ෂා කරන්න

Mould එක මාරු කිරීමට හෝ භාවිත කිරීමට පෙර වත්මන් පිහිටීම, තත්ත්වය, products සහ මෑත ඉතිහාසය බලන්න. සටහන් කර තිබේ නම් product විස්තරවල descriptions, cavities සහ photos පෙන්වයි.

ප්‍රතිඵලයක් නොපෙනේ නම් අක්ෂර වින්‍යාසය පරීක්ෂා කර filters ඉවත් කරන්න. Mould එක තවම ඇතුළත් කර නොමැති නම් supervisor අමතන්න.

ගබඩාවේ ඇති moulds සඳහා [ගබඩා ස්ථානය සොයන්න](rack-view.md) බලන්න.
