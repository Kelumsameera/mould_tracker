# Move a mould

1. Find the mould and open its details.
2. Choose the required destination from the available actions.
3. Select the machine or storage position when requested.
4. Add the required remarks and check the destination.
5. Save the movement and confirm the displayed location.

## Before saving

- Confirm that the mould ID matches the physical mould.
- Use a compatible, available machine.
- Choose an active, empty storage position. Each numbered position holds one mould.
- Moulds requiring service or repair must be handled through the workshop process before normal use or storage.

The available destinations depend on your access and the mould's condition. If the app refuses a move, read its message and correct the issue or contact your supervisor.

See [Find a storage position](rack-view.md) and [Workshop queue](workshop-queue.md).

## සිංහල

1. Mould එක සොයා එහි විස්තර විවෘත කරන්න.
2. පෙන්වන actions අතරින් අවශ්‍ය ගමනාන්තය තෝරන්න.
3. ඉල්ලන විට machine එක හෝ ගබඩා ස්ථානය තෝරන්න.
4. අවශ්‍ය remarks ඇතුළත් කර ගමනාන්තය පරීක්ෂා කරන්න.
5. Movement එක save කර පෙන්වන පිහිටීම තහවුරු කරන්න.

### Save කිරීමට පෙර

- Mould ID එක සැබෑ mould එකට ගැළපෙන බව තහවුරු කරන්න.
- ගැළපෙන සහ භාවිතයට ඇති machine එකක් තෝරන්න.
- ක්‍රියාත්මක, හිස් ගබඩා ස්ථානයක් තෝරන්න. එක් අංකිත ස්ථානයක තැබිය හැක්කේ එක් mould එකකි.
- Service හෝ repair අවශ්‍ය moulds සාමාන්‍ය භාවිතයට හෝ ගබඩාවට යැවීමට පෙර workshop ක්‍රියාවලිය අනුගමනය කළ යුතුයි.

ගමනාන්ත ඔබගේ අවසර සහ mould එකේ තත්ත්වය අනුව පෙන්වයි. App එක movement එක ප්‍රතික්ෂේප කරන්නේ නම් පණිවිඩය කියවා ගැටලුව නිවැරදි කරන්න හෝ supervisor අමතන්න.
