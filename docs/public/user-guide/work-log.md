# Record work

1. Open the mould's details.
2. Open the work log and choose the action to record work.
3. Select the type of work, describe what was done and identify the people who performed it.
4. Check the work date and time. Add time spent, parts used or photos where relevant.
5. Record the outcome and save.

Use clear, factual descriptions that help the next person understand the mould's condition. Record only work that was actually performed.

If an entry needs correction, use the available correction action rather than creating a misleading duplicate. Contact your supervisor if the action you need is unavailable.

To record an issue that has not yet been resolved, use [Report a problem](report-a-problem.md).
