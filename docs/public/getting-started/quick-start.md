# Quick start

## Find a mould

Open **Find a mould**, then search for a mould ID, product ID or description. Select the matching mould to see its current location and condition.

## Read the location

A storage label such as **FLK-A-P1-1** means zone FLK, rack A, pallet/level P1, position 1. Use [Rack view](../user-guide/rack-view.md) to see the physical layout.

## Record a movement

If you have movement access, open the mould and choose its destination. Check that the selected machine or storage position matches the physical destination before saving.

## Record a problem or completed work

Use **Report a problem** to describe an issue. Use the work log to record completed work when that action is available to you.

See [Using Mould Tracker](../user-guide/README.md) for the full list of user guides.

### ගබඩා ස්ථානය කියවන්න

**FLK-A-P1-1** යනු FLK කලාපය, A rack එක, P1 pallet/තට්ටුව සහ 1 ස්ථානයයි. භෞතික සැලැස්ම බැලීමට [Rack view](../user-guide/rack-view.md) භාවිත කරන්න.

### මාරු කිරීමක් සටහන් කරන්න
