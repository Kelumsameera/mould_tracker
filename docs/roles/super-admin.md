# Super Admin (`super_admin`)

## Can do
Everything Admin can, plus: change zones and racks, read the audit log, send moulds Out of Service and return them, and manage Admins and other Super Admins. Cannot manage custom access or see System Administrator accounts.

## Typical journey
Sign in → **Workshop queue** (anything stuck?) → **Audit log** (yesterday's overrides and deletes) → **Rack management** (new racks) → sign out.

## Pages
All sidebar pages except **User access**.
