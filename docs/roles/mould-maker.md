# Mould Maker (`mould_maker`)

## Can do
Moves into and out of the Mould Room / Tool Room (rack changes, storage → floor/workshop, back to a rack), send to the Workshop, change status, Workshop → floor, log work, report problems.

## Cannot do
Mount on machines or record shots (needs `moves.machine`), or manage anything.

## Typical journey
Sign in → **Workshop queue** → set **In repair** / **In service** → log work → mark **Good** → put it back on a rack (**Rack view** to find space) → sign out.
