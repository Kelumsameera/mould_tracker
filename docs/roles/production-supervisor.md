# Production Supervisor (`production_supervisor`)

## Can do
View everything operational; mount a mould from the floor or the Workshop onto a machine, change machines, move it machine → floor; record shots; report problems.

## Cannot do
Move into or out of storage, send to the Workshop, change status, log work, or manage anything.

## Typical journey
Sign in → **Find a mould** (search by machine code) → **Record shots** at shift end → **Report a problem** if something is wrong → hand off to the Mould Technician → sign out.
