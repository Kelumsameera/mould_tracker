# Admin (`admin`)

## Can do
Every move except Out of Service; mount on a non-listed machine with a reason; add/edit/delete/restore moulds and items; edit machines; manage users (not Super Admins); log work; work log report and export. Rack management is **view only**. No audit log.

## Typical journey
Sign in → **Find a mould** → add or correct moulds/items → **Machines** → **Users** (new starters) → **Work log report** (weekly export) → sign out.
