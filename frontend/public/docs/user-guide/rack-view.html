#Find a storage position

Open Rack view from the sidebar. Choose a zone or view all zones.

#Read the label

FLK-A-P1-1 means:

Part Meaning
FLK Storage zone
A Rack
P1 Pallet or level
1 Mould position

The rack layout shows blue frames, orange shelves and numbered positions. Occupied positions show the mould ID together with an available item photo and item ID. A small count indicates additional item photos; open the mould details to see its items. Positions without a photo still show their mould ID. Empty positions show an empty label. Dimmed positions are not in use.

#Find a mould

Search by mould ID, product ID, description or location. Matching positions stay highlighted. Select a position to filter the mould location table below the layout; select Show all to clear that selection.

The table shows the recorded mould and product details. Select a mould ID to open its details when you have viewing access.

Moulds listed under Waiting for a rack do not yet have a recorded storage position. Ask the person responsible for storage to assign the correct position.

#ගබඩා ස්ථානය සෙවීම

Sidebar එකෙන් Rack view විවෘත කරන්න. එක් කලාපයක් තෝරන්න හෝ සියලු කලාප බලන්න.

#ස්ථාන ලේබලය කියවන්න

FLK-A-P1-1 ලේබලයේ කොටස් පහත පරිදි වේ.

කොටස අර්ථය
FLK ගබඩා කලාපය
A Rack එක
P1 Pallet එක හෝ තට්ටුව
1 Mould එක තබන ස්ථානය

Rack සැලැස්මේ නිල් රාමු, තැඹිලි තට්ටු සහ අංකිත ස්ථාන පෙන්වයි. පිරී ඇති ස්ථානවල mould ID එකත්, තිබේ නම් item photo එක සහ item ID එකත් පෙන්වයි. කුඩා ගණනකින් තවත් item photos ඇති බව දක්වයි. ඒවා බැලීමට mould විස්තර විවෘත කරන්න. Photo එකක් නොමැති ස්ථානවලත් mould ID එක පෙන්වයි. හිස් ස්ථානවල හිස් බව දක්වන ලේබලයක් ඇත. අඳුරු කර ඇති ස්ථාන භාවිතයේ නැත.

#Mould එකක් සොයන්න

Mould ID, product ID, විස්තරය හෝ පිහිටීම අනුව සොයන්න. ගැළපෙන ස්ථාන highlight වේ. ස්ථානයක් තේරූ විට පහළ mould location table එක එම ස්ථානයට සීමා වේ. තේරීම ඉවත් කිරීමට Show all තෝරන්න.

Table එකේ සටහන් කළ mould සහ product විස්තර පෙන්වයි. බැලීමට අවසර තිබේ නම් mould ID එක තෝරා විස්තර විවෘත කරන්න.

Waiting for a rack යටතේ ඇති moulds සඳහා තවම ගබඩා ස්ථානයක් සටහන් කර නැත. නිවැරදි ස්ථානය ලබාදීමට ගබඩාව භාර පුද්ගලයාට දැනුම් දෙන්න.
