Download the app

These apps open Tool Tracker without browser menus or extension controls. Version 2.2.0.

Download Windows installer (.exe)

Windows 10/11, 64-bit. Install the factory certificate using the Windows steps below, then run the installer. This release has no publisher code signature, so Windows may show an unknown-publisher warning.

Download Android app (.apk)

Android 8 or later. Open the downloaded APK and allow installation from your browser when Android asks. The factory certificate is already included in this app; no separate certificate setup is needed. Use email/password to sign in.

Download SHA-256 checksums

Install your downloaded app

  1. Android: open the downloaded APK, allow installation from this browser if Android asks, and tap Install. The factory certificate is included in the APK.
  2. Windows: complete the Windows certificate setup below, then run the downloaded EXE and follow the installer. Open Mould Tracker from Start or your desktop.
  3. Connect to the factory network and sign in using the email and password assigned by your administrator. Native app passkey sign-in is not integrated; use your password.
Apple: iPhone / iPad / Mac

Native Apple downloads are not available yet. A Mac/Xcode build and Apple signing/distribution setup are required. Until those are ready, install the web app using the iPhone/iPad or Mac instructions below.

Or install the web app

1. Set up this device

Do this once on each device. Choose your device below, trust the factory certificate, then install the app.

Android
  1. Download factory certificate (.crt).
  2. Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate. Select the downloaded file and confirm. Menu names vary by phone.
  3. Restart Chrome and open Tool Tracker using the button below. The page should open without a certificate warning.
  4. Choose Install app on the login screen. If no prompt appears, use Chrome menu → Add to Home screen → Install.
  5. Open Tool Tracker from your home screen or app launcher.
iPhone / iPad
  1. Open this page in Safari. Download the factory certificate profile and allow the download.
  2. Settings → General → VPN & Device Management → install Tool Tracker LAN HTTPS.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for Tool Tracker LAN Root CA.
  4. Open Tool Tracker below in Safari. Tap Share → Add to Home Screen. Keep Open as Web App on if shown, then tap Add.
  5. Open Tool Tracker from the new home screen icon.
Windows
  1. Download factory certificate (.cer) and double-click it.
  2. Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities → Finish. Confirm Tool Tracker LAN Root CA.
  3. Close and reopen Chrome or Edge. Open Tool Tracker below and choose Install app on the login screen.
  4. If no prompt appears: in Edge, use menu → Apps → Install this site as an app; in Chrome, use menu → Cast, save, and share → Install page as app. Menu wording can vary.
  5. Open Tool Tracker from Start. Pin it to the taskbar for easy access.
Mac
  1. Download factory certificate (.crt). Open it in Keychain Access and add it to the login keychain.
  2. Open Tool Tracker LAN Root CA in Keychain Access → Trust → When using this certificate → Always Trust. Confirm your Mac credentials.
  3. Restart your browser. In Safari on macOS Sonoma or later, open Tool Tracker below → File → Add to Dock → Add.
  4. Alternatively, open in Chrome and choose Install app. Launch Tool Tracker from the Dock or app launcher.

Need a hand?

The app cannot connect

Check that your device is connected to the factory Wi-Fi/LAN and the server is running. Close and reopen the app. If it still fails, contact factory IT.

I see a certificate warning

Use the device setup instructions above. Ask factory IT to confirm the certificate if you are unsure; do not continue through an unexpected certificate warning.

I cannot sign in or see an action

Use your assigned account. Ask your administrator to check that it is active and has the required permissions, or to reset your password.

How do updates work?

The web UI updates from the factory server when you reopen the app. Native shell changes need a new APK or Windows installer. Android updates must use the same app signing identity.
